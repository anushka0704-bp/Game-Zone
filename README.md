# GameZone — Mini Gaming Website

A responsive browser-based mini gaming hub built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Four playable games: Tic-Tac-Toe, Memory Match, Number Guess and Rock Paper Scissors
- Game search and category filters
- Personal best records saved with localStorage
- Responsive layout and mobile navigation
- Developer profile section with editable name, email and GitHub placeholders
- No backend or installation required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. For development, use VS Code with the Live Server extension if available.

## Project structure
```text
GameZone/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Technologies
- HTML5: semantic page structure
- CSS3: layout, responsive design, animations and visual styling
- JavaScript: game logic, DOM events, search/filter and localStorage

## Notes
- Scores are saved only in the current browser on the current device.
- Google Fonts are loaded online; system fallbacks are provided.
- This is a front-end learning project. It does not use accounts, payments or a shared online leaderboard.

## Personalize before submission
- In `index.html`, replace `[Your Name]`, `your.email@example.com` and `your-username` with your real details.
- Update the About and Developer sections with your genuine education, skills and contribution.

## Before submission
